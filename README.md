# راهنمای انتشار روی Vercel

## ساختار
- index.html        صفحه اصلی (معرفی هوشیکا + فرم رزومه)
- logo*.png         لوگوی هوشیکا (نسخه کامل، فقط نوشته، فقط نماد)
- api/upload.js     تابع سرور‌لس برای دریافت و ذخیره رزومه
- package.json      وابستگی @vercel/blob

## مراحل
1. پروژه را در GitHub بگذارید (یا با `vercel` در ترمینال دیپلوی کنید).
2. در Vercel گزینه Add New → Project را بزنید و ریپو را انتخاب کنید.
   (Framework Preset: Other، بدون Build Command)
3. بعد از ساخته شدن پروژه: Storage → Create → Blob و آن را به پروژه وصل کنید.
   این کار متغیر BLOB_READ_WRITE_TOKEN را خودکار اضافه می‌کند.
4. یک بار Redeploy کنید.

رزومه‌ها در Storage → Blob داخل پوشه resumes/ ذخیره می‌شوند
(هر رزومه یک فایل info.json هم دارد که نام و ایمیل متقاضی در آن است).

## نکات
- حجم فایل حداکثر ۴ مگابایت است (محدودیت Vercel برای بدنه درخواست حدود ۴.۵ مگابایت).
- فایل‌ها با آدرس تصادفی و طولانی ذخیره می‌شوند اما از نوع public هستند؛
  لینک‌ها را با دیگران به اشتراک نگذارید.
- برای تست محلی: `npm i -g vercel` ← `vercel env pull` ← `vercel dev`
